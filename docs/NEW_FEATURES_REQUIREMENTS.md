# Спецификация новых функциональных требований

## Обзор
Документ описывает четыре новых модуля, интегрируемых в приложение Investing Demo.

---

## Модуль 1: Персональный мониторинг акций (Watchlists & Alerts)

### ФР-1.1: Создание списка наблюдения
- Система должна позволять авторизованному пользователю создавать именованный список наблюдения
- Каждый список принадлежит конкретному пользователю
- *Подтверждение:* `dashboard/models.py`, модель `Watchlist`

### ФР-1.2: Добавление акций в список наблюдения
- Система должна позволять добавлять акции из существующего каталога в список наблюдения
- Одна акция может быть в нескольких списках
- *Подтверждение:* `dashboard/models.py`, модель `WatchlistItem`

### ФР-1.3: Установка ценовых триггеров
- Система должна позволять устанавливать триггеры на целевые цены для акций в списке
- Типы триггеров: цена выше целевой, цена ниже целевой
- *Подтверждение:* `dashboard/models.py`, модель `PriceAlert`

### ФР-1.4: Автоматическая проверка триггеров
- Фоновый воркер должен регулярно проверять текущие цены против установленных триггеров
- При срабатывании триггер помечается как исполненный
- *Подтверждение:* `dashboard/services/alerts.py`, `check_price_alerts()`

### ФР-1.5: Защита от дублирования уведомлений
- При срабатывании триггера его статус меняется на `is_triggered=True`
- Повторная проверка не отправляет уведомление повторно
- *Подтверждение:* `dashboard/services/alerts.py`, проверка `is_triggered` перед действием

## Модуль 2: Виртуальный инвестиционный портфель

### ФР-2.1: Создание портфеля
- Система должна позволять авторизованному пользователю создавать именованный виртуальный портфель
- *Подтверждение:* `dashboard/models.py`, модель `Portfolio`

### ФР-2.2: Регистрация операций покупки/продажи
- Система должна позволять регистрировать операции BUY и SELL
- Каждая операция привязана к портфелю и акции
- *Подтверждение:* `dashboard/models.py`, модель `Transaction`

### ФР-2.3: Расчёт средней цены (средневзвешенная стоимость)
- Средняя цена = Σ(количество × цена покупки) / общее количество акций
- При продаже средняя цена не меняется, меняется количество
- *Подтверждение:* `dashboard/services/portfolio.py`, `calculate_average_price()`

### ФР-2.4: Расчёт P&L (прибыль/убыток)
- Абсолютный P&L = (текущая цена - средняя цена) × количество
- Процентный P&L = (абсолютный P&L / стоимость покупки) × 100%
- *Подтверждение:* `dashboard/services/portfolio.py`, `calculate_pnl()`

### ФР-2.5: История транзакций
- Система должна хранить полную историю всех операций с метаданными
- *Подтверждение:* `dashboard/models.py`, модель `Transaction`

## Модуль 3: История рыночных цен

### ФР-3.1: Автоматическое сохранение цен
- Фоновый воркер должен ежедневно сохранять дневные цены (OHLCV) для каждой акции
- *Подтверждение:* `dashboard/models.py`, модель `HistoricalPrice`

### ФР-3.2: Запрос истории за период
- Система должна позволять запрашивать цены за произвольный период
- Фильтрация по дате начала и окончания
- *Подтверждение:* `dashboard/api/v2/views.py`, `HistoricalPriceViewSet`

### ФР-3.3: Расчёт изменений за период
- Абсолютное изменение = цена_конца - цена_начала
- Процентное изменение = ((цена_конца / цена_начала) - 1) × 100%
- *Подтверждение:* `dashboard/services/price_history.py`, `calculate_period_change()`

### ФР-3.4: Визуализация на графиках
- Система должна строить линейные графики на основе исторических данных из БД
- *Подтверждение:* `dashboard/services/price_history.py`, `build_price_chart()`

---

## Модуль 4: Симулятор инвестиционных стратегий

### ФР-4.1: Создание стратегии
- Система должна позволять создавать стратегию с условиями входа/выхода
- Условия: цена упала/выросла на X%, цена ниже/выше Y
- *Подтверждение:* `dashboard/models.py`, `TradingStrategy`, `StrategyRule`

### ФР-4.2: Бэктестинг на исторических данных
- Система должна моделировать сделки на основе исторических цен из БД
- *Подтверждение:* `dashboard/services/backtester.py`, `run_backtest()`

### ФР-4.3: Журнал виртуальных сделок
- Каждая симулированная сделка записывается в БД
- *Подтверждение:* `dashboard/models.py`, модель `StrategyTrade`

### ФР-4.4: Метрики эффективности
- Итоговая доходность %, максимальная просадка, количество сделок, win rate
- *Подтверждение:* `dashboard/services/backtester.py`, `calculate_metrics()`
